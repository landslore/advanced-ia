# AI Builder desde cero

Itinerario interactivo de 12 semanas para construir proyectos con IA sin experiencia previa de programación, GitHub o GitHub Actions. Incluye talleres, cursos oficiales, autoevaluación por semana y checklist de proyecto final.

## Abrir localmente
Abre `index.html` en un navegador. El avance se guarda en el almacenamiento local del navegador.

## Publicar en GitHub Pages
1. Crea un repositorio vacío y publica esta carpeta con GitHub Desktop o Git.
2. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Guarda y abre la URL indicada por GitHub Pages.

El sitio es estático, no necesita compilación ni dependencias. `.nojekyll` permite servir los archivos directamente.
